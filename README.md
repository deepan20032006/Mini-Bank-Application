Excited to share my latest C++ project!

As a beginner exploring C++, I wanted to move beyond basic concepts and build something practical. So, I built a Console-Based Banking System from scratch using C++!

Key Features of this project:

Account creation (Name, Username, Password setup)

Secure Login authentication system

Balance checking & Money Transfer simulations

Utilized OOPs concepts (class), Vectors, and Pointers (struct & dynamic memory management).

While building this, I faced a few classic beginner bugs (especially around pointers and logic flows), but debugging them helped me understand C++ memory management much better!
